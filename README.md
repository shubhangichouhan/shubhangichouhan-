> *Jan 2026 – Present | Team Project*

An end-to-end AI application that automatically grades **handwritten answer sheets** using Vision AI (OCR) + LLM semantic evaluation.

- 🔻 **~70% reduction** in manual grading effort
- ⚙️ Configurable pipeline: variable exam structures, strictness levels, per-question confidence scoring
- 📊 Granular feedback: marks, keyword match, review flags
- 🗣️ Presented at **IIIT Naya Raipur Mid-Term Review, March 2026**
